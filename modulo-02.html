📦 ¿Qué es una Variable?

Una variable es como una caja donde guardamos información. Cada caja tiene:

  • Un nombre (para identificarla)
  • Un tipo (qué puede guardar)
  • Un valor (lo que contiene)

Analogía Simple

Imagina que tienes cajas etiquetadas en tu casa:

  • 📦 Caja "edad" → solo puede guardar números → contiene: 25
  • 📦 Caja "nombre" → solo puede guardar texto → contiene: "María"
  • 📦 Caja "esEstudiante" → solo puede guardar verdadero/falso → contiene: true

📝 Declaración de Variables

En C#, declaramos variables así:

// Sintaxis: tipo nombreVariable = valor;

int edad = 25;              // Número entero
string nombre = "María";    // Texto
bool esEstudiante = true;   // Verdadero o falso
double precio = 99.99;      // Número con decimales

🔢 Tipos de Datos Numéricos

Números Enteros

byte edad = 25;                    // 0 a 255
short temperatura = -15;            // -32,768 a 32,767
int poblacion = 1500000;            // El más común
long distancia = 9460730472580800L; // Números muy grandes

Números Decimales

float precio = 19.99f;     // 7 dígitos de precisión
double pi = 3.14159265358979; // 15-16 dígitos (más común)
decimal salario = 45000.50m; // 28-29 dígitos (ideal para dinero)

¿Cuál usar?

TipoUso Recomendado
intContadores, edades, cantidades
doubleCálculos científicos, mediciones
decimalDinero, finanzas (mayor precisión)

📝 Tipo de Dato Texto (string)

string nombre = "Ana";
string apellido = "García";

// Concatenación (unir textos)
string nombreCompleto = nombre + " " + apellido;

// Interpolación (forma moderna y recomendada)
Console.WriteLine($"Hola, soy {nombre} {apellido}");

// Propiedades útiles
Console.WriteLine(nombre.Length);      // 3 (longitud)
Console.WriteLine(nombre.ToUpper());   // ANA
Console.WriteLine(nombre.ToLower());   // ana

// Caracteres especiales
Console.WriteLine("Línea 1\nLínea 2");   // \n = nueva línea
Console.WriteLine("Col1\tCol2");         // \t = tabulación

✅ Tipo de Dato Booleano (bool)

Los booleanos solo pueden tener dos valores: true (verdadero) o false (falso).

bool esMayorDeEdad = true;
bool tieneDescuento = false;

// Booleanos a partir de comparaciones
int edad = 20;
bool puedeVotar = edad >= 18;  // true porque 20 >= 18

int saldo = 100;
bool puedeComprar = saldo >= 500;  // false porque 100 < 500

➕ Operadores Aritméticos

int a = 10;
int b = 3;

Console.WriteLine(a + b);   // Suma: 13
Console.WriteLine(a - b);   // Resta: 7
Console.WriteLine(a * b);   // Multiplicación: 30
Console.WriteLine(a / b);   // División: 3 (entera)
Console.WriteLine(a % b);   // Módulo (resto): 1

// Incremento y decremento
int contador = 5;
contador++;  // Ahora es 6
contador--;  // Ahora es 5

// Operadores de asignación compuesta
int numero = 10;
numero += 5;  // numero = numero + 5 → 15
numero -= 3;  // numero = numero - 3 → 12
numero *= 2;  // numero = numero * 2 → 24

⚖️ Operadores de Comparación

int a = 10, b = 5, c = 10;

a == b   // Igual a: false
a == c   // Igual a: true
a != b   // Diferente de: true
a > b    // Mayor que: true
a < b    // Menor que: false
a >= c   // Mayor o igual: true
a <= b   // Menor o igual: false

🔗 Operadores Lógicos

bool a = true;
bool b = false;

a && b   // AND: false (ambos deben ser true)
a || b   // OR: true (al menos uno debe ser true)
!a       // NOT: false (invierte el valor)

// Ejemplo práctico
int edad = 25;
bool tieneID = true;
bool enListaNegra = false;

bool puedeEntrar = (edad >= 18) && tieneID && !enListaNegra;
// true: es mayor, tiene ID, y NO está en lista negra

💻 Ejemplo Práctico: Calculadora de IMC

using System;

class CalculadoraIMC
{
    static void Main()
    {
        Console.WriteLine("╔════════════════════════════════════╗");
        Console.WriteLine("║   CALCULADORA DE IMC               ║");
        Console.WriteLine("╚════════════════════════════════════╝");
        
        Console.Write("Ingresa tu nombre: ");
        string nombre = Console.ReadLine();
        
        Console.Write("Ingresa tu peso en kg: ");
        double peso = double.Parse(Console.ReadLine());
        
        Console.Write("Ingresa tu altura en metros: ");
        double altura = double.Parse(Console.ReadLine());
        
        // Calcular IMC: peso / (altura * altura)
        double imc = peso / (altura * altura);
        
        // Determinar categoría
        string categoria;
        if (imc < 18.5)
            categoria = "Bajo peso";
        else if (imc < 25)
            categoria = "Peso normal";
        else if (imc < 30)
            categoria = "Sobrepeso";
        else
            categoria = "Obesidad";
        
        Console.WriteLine($"\nHola {nombre}, tu IMC es: {imc:F2}");
        Console.WriteLine($"Categoría: {categoria}");
    }
}
