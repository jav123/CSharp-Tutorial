📖 ¿Qué es C#?

C# (pronunciado "C Sharp") es un lenguaje de programación moderno, desarrollado por Microsoft en el año 2000. Es uno de los lenguajes más populares y versátiles del mundo.

¿Para qué se usa C#?

Tipo de Aplicación Ejemplos
Aplicaciones de escritorio Programas para Windows
Aplicaciones web Sitios web con ASP.NET
Videojuegos Juegos con Unity
Aplicaciones móviles Apps con Xamarin/MAUI
Servicios en la nube Azure Functions, APIs

¿Por qué aprender C#?

  1. Fácil de aprender - Sintaxis clara y legible
  2. Muy demandado - Muchas empresas lo usan
  3. Versátil - Sirve para muchos tipos de proyectos
  4. Gran comunidad - Mucha documentación y ayuda disponible
  5. Herramientas gratuitas - Visual Studio Community es gratis

🛠️ Instalación del Entorno de Desarrollo

Opción 1: Visual Studio (Recomendado para Windows)

Visual Studio es el IDE (Entorno de Desarrollo Integrado) más completo para C#.

Pasos de instalación:
  1. Ve a https://visualstudio.microsoft.com/es/
  2. Descarga Visual Studio Community (es gratis)
  3. Ejecuta el instalador
  4. Selecciona la carga de trabajo: "Desarrollo de escritorio y Web de .NET"
  5. Haz clic en "Instalar"

Opción 2: Visual Studio Code (Multiplataforma)

VS Code es más ligero y funciona en Windows, macOS y Linux.

Pasos de instalación:
  1. Descarga VS Code desde https://code.visualstudio.com/
  2. Instala VS Code
  3. Abre VS Code y ve a Extensiones (Ctrl+Shift+X)
  4. Busca e instala: "C# Dev Kit"
  5. Instala el SDK de .NET desde https://dotnet.microsoft.com/download

Verificar la instalación

Abre una terminal (CMD o PowerShell) y escribe:

dotnet --version

Deberías ver algo como: 8.0.100 (o una versión similar)

🚀 Tu Primer Programa: "Hola Mundo"

Es tradición que el primer programa que escribas muestre "Hola Mundo" en pantalla. ¡Vamos a hacerlo!

Crear el proyecto

En la terminal:

# Crear una carpeta para tus proyectos
mkdir MisProyectosCSharp
cd MisProyectosCSharp

# Crear tu primer proyecto
dotnet new console -n HolaMundo

# Entrar a la carpeta del proyecto
cd HolaMundo

El código

Al crear el proyecto, se genera automáticamente un archivo Program.cs. Modifícalo así:

// Program.cs - Mi primer programa en C#

// Mostrar un mensaje de bienvenida
Console.WriteLine("¡Hola Mundo!");
Console.WriteLine("Este es mi primer programa en C#");
Console.WriteLine("¡Estoy aprendiendo a programar!");

Ejecutar el programa

En la terminal, dentro de la carpeta del proyecto:

dotnet run
Resultado esperado: 
¡Hola Mundo!
Este es mi primer programa en C#
¡Estoy aprendiendo a programar!

🎉 ¡Felicidades! Has escrito y ejecutado tu primer programa en C#.

📝 Anatomía de un Programa C#

Veamos un programa más completo para entender sus partes:

// ============================================
// Programa: Saludo Personalizado
// Descripción: Pide el nombre al usuario y lo saluda
// ============================================

using System;  // Importa funcionalidades básicas

namespace MiPrimerPrograma  // Espacio de nombres
{
    class Program  // Una clase (contenedor de código)
    {
        static void Main(string[] args)  // Punto de entrada
        {
            // Mostrar mensaje pidiendo el nombre
            Console.WriteLine("¿Cómo te llamas?");
            
            // Leer lo que el usuario escribe
            string nombre = Console.ReadLine();
            
            // Mostrar saludo personalizado
            Console.WriteLine("¡Hola, " + nombre + "! Bienvenido a C#");
        }
    }
}

Explicación de cada parte:

Elemento Descripción
// Comentario - el programa lo ignora, es para humanos
using System; Importa funcionalidades que necesitamos
namespace Agrupa código relacionado (como una carpeta)
class Contenedor de código (lo veremos en POO)
static void Main() Punto de entrada - aquí comienza el programa
Console.WriteLine() Muestra texto en pantalla
Console.ReadLine() Lee texto que escribe el usuario
string nombre Variable que guarda texto

💻 Ejemplo Práctico: Calculadora Simple

Vamos a crear algo más interesante - una calculadora que suma dos números:

// ============================================
// Programa: Calculadora de Suma
// ============================================

using System;

class CalculadoraSuma
{
    static void Main()
    {
        // Título del programa
        Console.WriteLine("=================================");
        Console.WriteLine("    CALCULADORA DE SUMA");
        Console.WriteLine("=================================");
        Console.WriteLine();
        
        // Pedir el primer número
        Console.Write("Ingresa el primer número: ");
        string entrada1 = Console.ReadLine();
        int numero1 = int.Parse(entrada1);
        
        // Pedir el segundo número
        Console.Write("Ingresa el segundo número: ");
        string entrada2 = Console.ReadLine();
        int numero2 = int.Parse(entrada2);
        
        // Calcular la suma
        int resultado = numero1 + numero2;
        
        // Mostrar el resultado
        Console.WriteLine();
        Console.WriteLine($"Resultado: {numero1} + {numero2} = {resultado}");
    }
}
Ejecución del programa: 
=================================
    CALCULADORA DE SUMA
=================================

Ingresa el primer número: 15
Ingresa el segundo número: 27

Resultado: 15 + 27 = 42

Conceptos nuevos:

  • Console.Write() - Escribe sin saltar de línea
  • int.Parse() - Convierte texto a número entero
  • int - Tipo de dato para números enteros
  • $"texto {variable}" - Interpolación de strings
