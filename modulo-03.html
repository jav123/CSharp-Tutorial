🔹 Condicional IF

El if ejecuta código solo si una condición es verdadera.

// Sintaxis básica
if (condición)
{
    // Código si es verdadero
}

// Ejemplo
int edad = 20;

if (edad >= 18)
{
    Console.WriteLine("Eres mayor de edad");
}

🔹 IF - ELSE

int numero = 7;

if (numero % 2 == 0)
{
    Console.WriteLine($"{numero} es PAR");
}
else
{
    Console.WriteLine($"{numero} es IMPAR");
}

🔹 IF - ELSE IF - ELSE

int nota = 85;
string letra;

if (nota >= 90)
{
    letra = "A";
}
else if (nota >= 80)
{
    letra = "B";
}
else if (nota >= 70)
{
    letra = "C";
}
else if (nota >= 60)
{
    letra = "D";
}
else
{
    letra = "F";
}

Console.WriteLine($"Tu calificación es: {letra}");

🔹 Operador Ternario

Forma corta de escribir un if-else simple:

// condición ? valorSiTrue : valorSiFalse

int edad = 20;
string resultado = edad >= 18 ? "Mayor" : "Menor";

int numero = 7;
string paridad = numero % 2 == 0 ? "Par" : "Impar";

🔹 SWITCH

int dia = 3;
string nombreDia;

switch (dia)
{
    case 1:
        nombreDia = "Lunes";
        break;
    case 2:
        nombreDia = "Martes";
        break;
    case 3:
        nombreDia = "Miércoles";
        break;
    case 4:
        nombreDia = "Jueves";
        break;
    case 5:
        nombreDia = "Viernes";
        break;
    case 6:
    case 7:
        nombreDia = "Fin de semana";
        break;
    default:
        nombreDia = "Día inválido";
        break;
}

Console.WriteLine(nombreDia);

Switch Expression (C# 8+)

string nombreDia = dia switch
{
    1 => "Lunes",
    2 => "Martes",
    3 => "Miércoles",
    4 => "Jueves",
    5 => "Viernes",
    6 or 7 => "Fin de semana",
    _ => "Día inválido"
};

🔄 Bucle FOR

Repite código un número específico de veces.

// Sintaxis: for (inicio; condición; incremento)

// Contar del 1 al 10
for (int i = 1; i <= 10; i++)
{
    Console.WriteLine($"Número: {i}");
}

// Contar de 2 en 2
for (int i = 0; i <= 20; i += 2)
{
    Console.Write($"{i} ");
}

// Cuenta regresiva
for (int i = 10; i >= 0; i--)
{
    Console.WriteLine(i);
}
Console.WriteLine("¡Despegue!");

Tabla de Multiplicar

int numero = 7;

Console.WriteLine($"Tabla del {numero}");
for (int i = 1; i <= 10; i++)
{
    int resultado = numero * i;
    Console.WriteLine($"{numero} × {i} = {resultado}");
}

🔄 Bucle WHILE

Repite mientras una condición sea verdadera.

// Adivina el número
Random random = new Random();
int numeroSecreto = random.Next(1, 101);
int intento = 0;

while (intento != numeroSecreto)
{
    Console.Write("Adivina (1-100): ");
    intento = int.Parse(Console.ReadLine());
    
    if (intento < numeroSecreto)
        Console.WriteLine("Mayor...");
    else if (intento > numeroSecreto)
        Console.WriteLine("Menor...");
}

Console.WriteLine("¡Correcto!");

🔄 Bucle DO-WHILE

Similar al while, pero siempre ejecuta al menos una vez.

int opcion;

do
{
    Console.WriteLine("═══ MENÚ ═══");
    Console.WriteLine("1. Opción A");
    Console.WriteLine("2. Opción B");
    Console.WriteLine("0. Salir");
    Console.Write("Elige: ");
    
    opcion = int.Parse(Console.ReadLine());
    
    switch (opcion)
    {
        case 1: Console.WriteLine("Elegiste A"); break;
        case 2: Console.WriteLine("Elegiste B"); break;
        case 0: Console.WriteLine("¡Adiós!"); break;
    }
    
} while (opcion != 0);

🔄 Bucle FOREACH

Recorre colecciones de elementos.

string[] frutas = { "Manzana", "Naranja", "Plátano" };

foreach (string fruta in frutas)
{
    Console.WriteLine($"Fruta: {fruta}");
}

// Sumar números
int[] numeros = { 10, 20, 30, 40, 50 };
int suma = 0;

foreach (int num in numeros)
{
    suma += num;
}
Console.WriteLine($"Suma total: {suma}");

⏹️ BREAK y CONTINUE

// BREAK - Sale del bucle
for (int i = 1; i <= 10; i++)
{
    if (i == 5)
        break;  // Sale cuando i es 5
    Console.WriteLine(i);
}
// Imprime: 1, 2, 3, 4

// CONTINUE - Salta a la siguiente iteración
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
        continue;  // Salta los pares
    Console.WriteLine(i);
}
// Imprime: 1, 3, 5, 7, 9
